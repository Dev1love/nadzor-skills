# Аудит безопасности demo-shop

К релизу проект не готов. Любой покупатель может стать админом, читать данные из любой таблицы через SQL-инъекцию, смотреть чужие заказы и помечать заказы оплаченными без оплаты. Всё проверял только локально: временная база, свободный порт, тестовые пользователи. Код не менял. `AGENT_REPORT.md` расходится с кодом: подписи вебхука нет, доставка по зонам не сделана, чужие заказы видны, в профиле можно менять любые поля, а не только имя и телефон.
