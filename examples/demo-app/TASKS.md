# Задачи

## #1 Каркас магазина [готово]
Каталог товаров, регистрация, вход по токену. Каталог публичный, без входа.

## #2 Убрать секреты из репозитория [готово]
Ключи платёжки только через переменные окружения, `.env` не коммитим.

## #3 Заказы, промокоды, оплата [в работе]
- Покупатель оформляет заказ из корзины: товары, адрес, телефон, зона доставки, промокод.
- Сумма: товары минус скидка по промокоду (скидка округляется до рубля) плюс доставка.
- Доставка: `msk` 300 ₽, `spb` 400 ₽, остальные зоны 600 ₽. От 5000 ₽ доставка бесплатная.
- Промокод действует до конца дня `expires_at` включительно и не больше `max_uses` раз.
- Покупатель видит только свои заказы.
- Перед оформлением можно посмотреть расчёт суммы (preview), он должен совпадать с суммой заказа.
- Оплата: PayGate присылает вебхук на `/api/webhooks/payment`. Проверять подпись HMAC-SHA256 из заголовка `X-PayGate-Signature` секретом `PAYGATE_WEBHOOK_SECRET`. Заказ становится `paid`, только если сумма в вебхуке совпадает с суммой заказа.
- После оплаты письмо покупателю.
- Профиль: покупатель может поменять имя и телефон.
- Админ видит все заказы и выгружает CSV для бухгалтерии.

## #4 Промокод работает сверх лимита [баг]
Промокод с `max_uses = 1` можно применять сколько угодно раз: счётчик `used` не растёт.
