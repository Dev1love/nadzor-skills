# Демо: test-auditor

**Пять зелёных тестов, которые ничего не ловят**

Функция `canWithdraw`: можно ли снять деньги с учётом овердрафта и заморозки. Агент написал 5 тестов, все зелёные.

## Запуск
```bash
demos/run.sh test-auditor              # интерактивно, для сцены
demos/run.sh test-auditor --headless   # репетиция: печатает отчёт
```
Запрос к скиллу: `demos/test-auditor/prompt.txt`. Пример готового отчёта: [`sample-report.md`](sample-report.md) (запасной вариант, если живой прогон не успеет).

## Что заложено
Этот файл в копию для скилла не попадает.

- Тест «returns a boolean»: пустой.
- «allows a small withdrawal»: дубль соседнего.
- «blocks a frozen account»: мокает саму `canWithdraw` и проверяет мок.
- Не проверены граница (`amount === balance + overdraft`), овердрафт, заморозка.
- Саботаж: `<=` на `<`, убрать проверку заморозки, убрать овердрафт: все 5 тестов остаются зелёными (проверено).

## Чего ждать
Таблица вердиктов (1 пустой, 1 дубль, 1 мок самого себя, 2 ОК), саботаж в живую: код сломан, тесты зелёные, дерево откачено.

## Что сказать
Зелёные тесты не доказательство. Доказательство: сломать код и увидеть, что тест упал.
