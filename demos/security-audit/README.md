# Демо: security-audit

**Заметки: Боб читает Алису и делает себя админом**

API заметок без фреймворка. Агент добавил просмотр заметки по id, редактирование профиля и список пользователей для админа.

## Запуск
```bash
demos/run.sh security-audit              # интерактивно, для сцены
demos/run.sh security-audit --headless   # репетиция: печатает отчёт
```
Запрос к скиллу: `demos/security-audit/prompt.txt`. Пример готового отчёта: [`sample-report.md`](sample-report.md) (запасной вариант, если живой прогон не успеет).

## Что заложено
Этот файл в копию для скилла не попадает.

- `GET /api/notes/:id` не проверяет владельца: Боб читает заметку Алисы.
- `PATCH /api/me` делает `Object.assign(user, body)`: Боб шлёт `{"role":"admin"}` и открывает `/api/admin/users`.
- Ловушки: `DELETE /api/notes/:id` владельца проверяет; `/api/admin/users` проверяет роль на сервере. Скилл не должен их ругать.
- Побочно реальное: нет лимита попыток входа и размера тела запроса, сессии бессрочные, через тот же `PATCH /api/me` можно сменить `id` и `passwordHash`.

## Чего ждать
Две критичные находки, каждая доказана запросом с токеном другого пользователя (команда и ответ в отчёте). Ловушки в разделе «проверено, проблем нет».

## Что сказать
Скилл не говорит «уязвимо», он показывает запрос, которым это доказано. И так же доказывает, что исправлено.
