# Демо для показа

Шесть маленьких проектов, по одному на скилл. В каждом 2–4 яркие проблемы и одна ловушка: место, которое выглядит плохо, но правильное. Ловушка показывает, что скилл не ругает всё подряд.

- Без зависимостей: только Node 22+ (`node:http`, `node:test`), ничего ставить не нужно, сеть не нужна.
- История git собирается из шагов `demos/<демо>/steps/`: виден каждый коммит, ветка агента, удалённый `.env`.
- Скилл получает чистую копию во временной папке. Памятка с ответами (`README.md` демо) в копию не попадает.

## Запуск
```bash
demos/run.sh verify-claims              # интерактивная сессия Claude Code (для сцены)
demos/run.sh verify-claims --headless   # репетиция: отчёт в терминал
```
`run.sh` собирает копию, кладёт в неё только нужный скилл и запускает `claude` с запросом из `prompt.txt`. На сцене удобно заранее открыть сессию в режиме, который не спрашивает разрешение на каждую команду.

## Порядок для доклада

| # | Демо | Сюжет | Главный момент |
|---|---|---|---|
| 1 | [verify-claims](verify-claims/README.md) | «Скидки готовы, тесты проходят» | доклад агента против диффа и запусков |
| 2 | [test-auditor](test-auditor/README.md) | 5 зелёных тестов на снятие денег | саботаж: код сломан, тесты зелёные |
| 3 | [principles-review](principles-review/README.md) | Письмо и чек после заказа | три исхода: править, решать вам, оставить |
| 4 | [security-audit](security-audit/README.md) | Заметки | Боб читает Алису и делает себя админом, доказано запросами |
| 5 | [leak-guard](leak-guard/README.md) | Лендинг с заявками | светофор для не разработчика, ключ в истории git |
| 6 | [task-trail](task-trail/README.md) | «Почему лимит 7000?» | цепочка «строка, коммит, задача» и где она рвётся |

Время и цена прогона каждого демо: в конце его `sample-report.md`. Если живой прогон не успевает, покажите `sample-report.md`.

## Пересобрать демо
```bash
demos/build.sh security-audit /tmp/notes   # собрать репозиторий с историей
cd /tmp/notes && git log --oneline --all && npm test
```
